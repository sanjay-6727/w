# Movie Booking Vue Frontend

A beginner-friendly Vue 3 frontend for the existing Spring Boot Movie Booking API. It only uses endpoints already defined in `mbController.java`.

## Pages

- `/` - Home page
- `/movies` - Add, list, update and delete movies; search by name; filter by genre; show movies with/without bookings; sort by price.
- `/bookings` - Add, list, update and delete bookings; search by customer; view bookings for one movie.
- `/reports` - Movie/booking counts, total seats, average/minimum/maximum movie price, booking counts and seat totals by movie, movies with/without bookings.

## Run it

### 1. Start backend and MongoDB

Start the existing Spring Boot project. The API is expected at `http://localhost:8080/api`.

### 2. Start Vue

Install Node.js if needed. Open a terminal in this frontend folder and run:

```bash
npm install
npm run dev
```

Open the local address printed by Vite, usually `http://localhost:5173`.

## Important

- The backend must allow requests from the Vue development server (`http://localhost:5173`) through CORS. If the browser reports a CORS error, add a CORS configuration in the existing Spring Boot backend.
- Movie and booking IDs are MongoDB IDs generated by the backend.
- When deleting a movie, the backend also deletes its related bookings.
- The frontend is intentionally kept simple so it is easy to read and modify.
